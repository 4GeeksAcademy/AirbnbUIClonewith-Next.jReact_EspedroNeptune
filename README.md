# AirbnbUIClonewith-Next.jReact_EspedroNeptune

## Stayfinder

A mobile-first vacation rental UI with home, catalog, and room detail views. The visual direction follows the supplied Airbnb reference screenshots; listing data is mocked and listing photos load from Unsplash.

## Run locally

```bash
npm install
npm run dev
```

Open the URL printed by Next.js. The main routes are `/`, `/catalog`, and `/rooms/coastal-house`.

## Stack

- Next.js 16 App Router, React, and TypeScript
- Tailwind CSS 4 for component styling
- Lucide React icons

Run `npm run typecheck` and `npm run build` to validate the app.
